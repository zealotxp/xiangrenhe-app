湘仁禾私域会员 APP · 前端静态原型总览

依据《湘仁禾私域会员APP开发需求方案 v1》制作的多页面（MPA）原型。26 个业务页面 + 本总览页，纯原生 HTML/CSS/JS，双击 index.html 即可运行，页面之间为真实链接跳转。下方缩略图可点击文字标题进入对应页面。

26业务页面
5功能模块
6级角色体系
375×812手机视口

一、入口与归属

覆盖「注册流程 / 门店申请 / 归属关系绑定」：含是否绑定推广员的权限分支演示。

index.html 启动登录
微信授权 + 手机号验证码；经推广员链接进入即自动绑定归属
store-apply.html 门店申请
门店信息表单 + 审核进度（实体/虚拟门店均可）
invite.html 推广码与邀请
门店推广码、会员注册链接、已绑定推广员列表

二、直播模块

私域直播（不带货）、防挂机签到、红包发放与市代配置；未绑定推广员时直播入口整体隐藏。

live.html 直播 Tab
直播中 / 预告 / 录播回放三档切换与互动能力
live-room.html 直播间
看播计时、防挂机签到倒计时、红包领取、聊天抽奖
live-replay.html 录播回放
回放播放器、章节列表、观看记录
wallet.html 我的红包
红包余额、收入/支出明细、提现申请
redpacket-config.html 市代配置
本市红包金额、签到次数、账户充值与补发

三、商城与积分

产品展示中心（仅展示不销售）与积分商城（仅积分兑换）分开运营。

mall.html 商城 Tab
两个板块切换：产品展示中心 / 积分商城
product-detail.html 产品详情
规格参数、图文介绍、扫码登记引导
brand.html 企业介绍
企业简介 / 公司荣誉 / 发展历程 / 公司动态
news.html 公司新闻列表
分类筛选、置顶头条、图文列表
news-detail.html 资讯详情
图文正文、本场数据、点赞分享
points-mall.html 积分商城
积分商品、积分不足引导、兑换确认
points.html 我的积分
获取 / 使用记录与积分规则
exchange.html 收货地址
积分兑换与实物奖品共用的地址表单

四、一物一码抽奖

卡片随礼盒发放、每盒一码、APP 内扫码；微信扫码提示下载 APP。

scan.html 扫码
取景框、手动输码、扫码记录、微信扫码引导
lottery.html 抽奖
转盘抽奖、四档奖项配置、积分自动到账
my-prizes.html 中奖记录
待处理 / 已完成筛选与发货状态

五、数据与我的

多级角色数据看板（总部/省代/市代/门店/推广员）+ 个人中心与设置。

promotion.html 推广中心
分销聚合入口：数据看板、我的团队、归属、推广码、门店
dashboard.html 数据看板
五级角色切换，各自查看自身及下级数据
my-team.html 我的团队
顾客列表、搜索筛选、顾客行为弹窗
profile.html 我的 Tab
资产入口、归属链路、角色视角切换演示
settings.html 设置
通知开关、隐私、数据导出与删除、绑定状态演示

说明

1. 本原型为静态演示，不接后端；数据写在页面里，登录状态与演示角色存在浏览器 localStorage。
2. 品牌主色（深墨绿 + 禾金）为占位方案，待客户确认；改色只需调整 assets/style.css 的 :root 变量。
3. 直播功能依赖第三方平台，哪些能力能对接自有后台暂未确定，原型按「APP 内可看播、可签到、可领红包」实现。
4. 需求中的举例（如「200 元产品 = 200 积分」「一场两次签到」）仅作示例数据展示，实际值均由后台配置。
